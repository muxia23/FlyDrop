# Fly Drop

基于 python 的局域网跨平台文件传输和粘贴板共享系统

## 功能
- 局域网设备自动发现（UDP 广播），也支持手动添加设备
- 浏览对方共享目录，多选下载文件，文件 / 文件夹打包（zip）下载，带进度条
- 剪贴板共享：手动获取 / 发送剪贴板，或开启自动双向同步
- 设置页面：修改设备名称（热更新）、共享目录、访问密码、IP 白名单、端口、HTTPS，以及下载目录等客户端设置
- HTTPS 自签名证书自动生成、访问密码 / IP 白名单认证、访问日志

## 使用说明
1. 安装依赖（Python 3.9+）：
   ```bash
   pip install -r requirement.txt
   ```
2. 启动后端（每台需要共享文件的设备都要启动）：
   ```bash
   cd backend
   python main.py
   ```
3. 启动前端：
   ```bash
   cd frontend
   python main.py
   ```

也可以在项目根目录用 `python -m backend.main` / `python -m frontend.main` 启动。

首次启动会在 `backend/`、`frontend/` 目录下分别生成 `config.json`，
后端日志保存在 `backend/logs/`，自签名证书保存在 `backend/cert.pem`、`backend/key.pem`。

### 设置
点击文件页右上角的 “⚙ 设置”：
- **客户端**：下载目录、访问其他设备时使用的密码、本机后端地址、剪贴板自动同步开关与间隔
- **本机共享**：设备名称、共享目录、访问密码、IP 白名单、服务端口、广播端口、HTTPS（端口和 HTTPS 修改后需重启后端）

### 剪贴板共享
在 “📋 剪贴板” 标签页中操作，目标设备与文件页选中的设备一致：
- “获取对方剪贴板” / “复制到本机剪贴板”
- “发送本机剪贴板” / “发送文本框内容”
- 勾选 “自动同步” 后，双方复制的文本会自动同步（目前仅支持文本）

## 常见问题
1. 为什么别人发现不了我的设备？
   可能是因为局域网路由器设置了内网隔离，导致 udp 广播无法正确被接受；
   Windows 上还需要在防火墙中允许 Python 访问网络（首次启动时弹窗选择“允许”）。
   发现不了时可以用 “添加设备” 手动输入 `IP:端口`。
2. 提示“未授权访问”？
   对方设置了访问密码，在 “⚙ 设置 → 客户端 → 访问其他设备的密码” 中填写对方的密码，或让对方把你的 IP 加入白名单。
3. Linux 下剪贴板共享失败？
   需要安装 `xclip`、`xsel`（X11）或 `wl-clipboard`（Wayland）。
